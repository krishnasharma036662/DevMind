# Repository Knowledge Model (RKM)

The RKM is DevMind's canonical repository model.

Nodes represent software entities such as repositories, directories, files,
classes, functions, methods, variables, APIs and tests.

Edges represent relationships such as CONTAINS, IMPORTS, CALLS, DEPENDS_ON,
INHERITS, IMPLEMENTS, EXPOSES and TESTS.

All deterministic engineering modules consume the same RKM.

# DevMind Backend

Node.js + Express REST backend for DevMind.

## Architecture

Repository -> Repository Intelligence Engine -> RKM -> Engineering Intelligence
-> AI Explanation Layer -> Dashboard.

## Locked engineering stack

- Node.js
- Express.js
- MongoDB + Mongoose
- Tree-sitter
- Custom RKM
- Custom graph algorithms
- LangChain
- Sentence Transformers
- OpenAI OR Gemini

This repository is the architecture skeleton. Deterministic algorithms are
implemented module-by-module according to the six-month development plan.
